문제

  • 토큰 폭증 — AI 에이전트가 복잡한 DOM을 매 단계 LLM에 보내 토큰 10만+ 소모
  • 실패율 80% — SAP·공공 포털·복잡 SaaS에서 DOM 재추론 실패 반복
  • Active-X·법정양식 — Chrome MCP·Claude Computer Use 단독으로 자동화 불가
  • 사이트 운영자의 AI 리스크 — 에이전트가 UI 잘못 눌러 주문 오류·민원 증가
  • 벤더 록인 우려 — Anthropic 단독, OpenAI 단독 표준은 경쟁사 에이전트 차별

해결

  • ai-manifest.json 배포 — 사이트가 에이전트 전용 지침서를 직접 선언
  • SHA-256 해시 검증 — 중앙 레지스트리로 위조 차단 (특허 청구항 2)
  • 3가지 배포 방식 — /.well-known · <meta> · HTTP 헤더 (청구항 3)
  • Active-X·공인인증서 대응 — manual_signature · action_fallback 표준 명시
  • MIT + FRAND + IETF — 벤더 중립 · 표준화 진행 중

작동 원리 — 3단계

1

배포

사이트 운영자(또는 SI 파트너)가 /.well-known/ai-manifest.json에 지침서를 배포. HTTP 헤더 X-AI-Manifest 도 병행 가능.

2

조회·검증

AI 에이전트가 매니페스트를 1회 fetch. SHA-256 해시를 중앙 레지스트리에 조회해 white/gray/black 신뢰도 판정.

3

실행

검증 통과 시 매니페스트의 steps 배열을 순차 실행. DOM 재추론 없이 결정론적 조작. 토큰 95~98% 절감.
